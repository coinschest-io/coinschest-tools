# CoinsChest — открытый дешифратор

Код, которым монеты CoinsChest проверяются и открываются. Это не весь сайт —
только та часть, которую покупателю нужно уметь проверить и запустить **без
нас**: разбор секретной фразы, сверка монеты и сборка приватного ключа по
стандарту **BIP-38 (режим EC-multiply)**.

Зеркало существует ровно для одного обещания со страницы «Открытый код»: даже
если coinschest.io однажды исчезнет, монета остаётся рабочей. Здесь лежит всё,
что для этого нужно.

- Зеркала: **github.com/coinschest-io/coinschest-tools** · **codeberg.org/coinschest-io/coinschest-tools**
- Лицензия: **MIT** (см. `LICENSE`)
- Криптография не наша: это BIP-38, опубликованный в 2011 году. Копия текста
  стандарта — `docs/crypto/BIP-0038.mediawiki` (public domain).

## Что внутри

| Путь | Что это |
|---|---|
| `app/resources/js/lib/bip38.js` | Реализация BIP-38 (EC-multiply). Ядро. |
| `app/resources/js/lib/phrase.js`, `words.js` | Секретная фраза: создание и сверка, словарь на 1024 слова. |
| `app/resources/offline/` | Офлайн-файл: та же логика в одном HTML без интернета. |
| `app/scripts/build-offline.mjs` | Сборка офлайн-файла и его отпечатка sha256. |
| `app/scripts/bip38-vectors.mjs` | Прогон официальных векторов BIP-0038. |
| `docs/crypto/bip38-ec-multiply-vectors.json` | Официальные тест-векторы. |
| `docs/crypto/dictionary-ru-latin-1024.txt` | Словарь фраз (+ как он собран: `build_dict.py`). |
| `docs/crypto/crypto-spec-product3.md` | Как устроена проверяемая монета, по шагам. |
| `docs/crypto/BIP-0038.mediawiki` | Копия самого стандарта. |

Файлы в `app/` — **байт-в-байт** те же, что работают на сайте и в заказе.
В этом и смысл: «проверено на сайте» и «проверено у себя дома» — одно и то же
утверждение, а не два разных.

## Скачать готовый файл

Собирать ничего не нужно: офлайн-файл — это одна HTML-страница.

1. Откройте раздел **Releases** зеркала и скачайте из последнего выпуска
   файл `coinschest-offline.html`:
   - GitHub: <https://github.com/coinschest-io/coinschest-tools/releases/latest>
   - Codeberg: <https://codeberg.org/coinschest-io/coinschest-tools/releases>

   Тот же файл лежит на сайте: <https://coinschest.io/open>.
2. Сверьте отпечаток файла с эталоном (см. «Отпечаток» ниже).
3. Отключите интернет и откройте файл двойным щелчком — в любом современном
   браузере. Файл создаёт фразу, проверяет монету и выдаёт приватный ключ,
   ничего и никуда не отправляя. При каждом открытии он сам прогоняет
   официальные векторы BIP-38 и показывает результат вверху страницы.

### Отпечаток

Выпуск **1.0.0** (сборка 2026-10-05):

```
d542cf3959d55e514133807a5105cd60a9a218812ed0a0bfc9de0948515ed2df
```

Тот же отпечаток напечатан в инструкции к монете и показан на
<https://coinschest.io/open>. Посчитать отпечаток у скачанного файла:

| Система | Команда (в папке с файлом) |
|---|---|
| macOS | `shasum -a 256 coinschest-offline.html` (программа «Терминал») |
| Linux | `sha256sum coinschest-offline.html` |
| Windows | `certutil -hashfile coinschest-offline.html SHA256` (меню «Пуск» → `cmd`) |

Совпали все 64 знака — файл тот самый, откуда бы он ни был скачан. Не совпал —
не открывайте его и скачайте заново из другого зеркала.

## Собрать самому

Для тех, кто не хочет верить даже готовому файлу: соберите его из исходников и
убедитесь, что получился тот же отпечаток.

### 1. Установите Node.js

Нужна версия **20 или новее**, лучше LTS: <https://nodejs.org/ru/download>.

- **Windows, macOS** — установщик с сайта, дальше «Далее → Далее».
- **Linux** — пакетный менеджер дистрибутива или инструкция на том же сайте.

Проверка: в терминале `node -v` печатает `v20…` или выше, `npm -v` — номер версии.

### 2. Скачайте код

С git:

```bash
git clone https://github.com/coinschest-io/coinschest-tools.git
# или зеркало:
git clone https://codeberg.org/coinschest-io/coinschest-tools.git
```

Без git: на странице репозитория **Code → Download ZIP** (GitHub) или
**··· → Download ZIP** (Codeberg), затем распакуйте архив.

### 3. Поставьте зависимости и проверьте

```bash
cd coinschest-tools/app

# Строго по package-lock.json. Именно npm ci, а не npm install:
# другие версии библиотек дадут другой отпечаток.
npm ci

# Официальные векторы BIP-0038 — реализация обязана их пройти.
npm test
# → в конце «Всё сошлось»

# Офлайн-файл и его отпечаток.
npm run build:offline
# → public/downloads/coinschest-offline.html
# → sha256: d542cf39…
# → сверка: совпадает с опубликованным отпечатком выпуска 1.0.0
```

Дата сборки и эталонный отпечаток выпуска записаны в
`app/resources/offline/release.json`, поэтому файл получается одинаковым в
любой день и на любой машине. Строка «сверка» сравнивает результат с эталоном
сама.

### Если что-то не так

- **`npm` не найден / `node -v` меньше 20** — переустановите Node.js по шагу 1 и
  откройте новое окно терминала.
- **`npm ci` ругается на отсутствие `package-lock.json`** — вы не в той папке:
  команды запускаются из `coinschest-tools/app`.
- **Отпечаток не совпал** — проверьте, что зависимости ставились через `npm ci`
  и что код скачан из тега выпуска (`git checkout v1.0.0`), а не из свежей
  ветки с правками после него.

## Если программа-дешифратор исчезнет

Ключ зашифрован по открытому стандарту, который понимают десятки сторонних
программ. Наша — лишь одна из них. По тексту `docs/crypto/BIP-0038.mediawiki`
и векторам рядом ключ восстанавливается и вручную. Монета не зависит ни от
этого репозитория, ни от нас.

> Фразу и приватный ключ не сообщайте никому — ни в какой «поддержке», ни по
> какой ссылке. Этот код работает у вас на устройстве и наружу не ходит.
